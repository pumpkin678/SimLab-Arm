# 教学任务说明

本页说明教学目标、成员职责、工况和评价口径。当前提供四类教学工况及离线指标计算，教学通过阈值与最终提交格式尚待确定；Arm 仍是零力矩骨架。

## 教学目标

围绕同构控制器提供的六轴目标位置，让成员学习机械臂规划与控制，使机械臂能够快速、稳定地跟随目标，并能解释自己的算法选择与实际表现。训练在仿真中完成，获得的经验用于后续实物机械臂开发。

当前通过 GUI 手动输入和程序工况构造目标序列，成员不需要实际操作者输入即可开始调试。

学习内容包括理解关节目标和反馈、设计内部规划与控制过程、通过数据观察误差与振荡，以及分析模型约束和力矩限制对表现的影响。具体算法路线由成员设计，框架不预设 Arm 内部管线。

## 框架与成员职责

| 部分 | 当前职责 |
| --- | --- |
| 框架 | 模型与 MuJoCo 接入、目标输入、物理周期调度、关节反馈和力矩映射、GUI、benchmark 执行及统一 trace |
| 成员实现 | 在 `simulation/arm/` 内实现 Arm 的规划和控制逻辑，管理内部状态，在 update 中返回请求力矩，在 reset 中恢复内部状态 |
| 教学任务 | 给定参考工况和评价口径；通过阈值、阶段交付及允许修改范围尚待确定 |

实现从 [Arm](../simulation/arm/arm.hpp) 接入。成员可以自行组织 `simulation/arm/` 内部代码；共用输入输出接口、模型和记录格式是不同实现进行对比的基础。

### 实现边界

外部只提供目标位置，内部所需的参考加工、规划与控制由成员设计。接口字段、单位、周期时序和复位契约见 [架构说明](architecture.md#控制周期与接口)，坐标、零位和模型约束见 [资产说明](../assets/README.md)。

参考实现的参数和调试效果不自动构成教学要求；正式任务需要另行明确允许修改的范围和验收条件。

## 开发与观察

1. 按 [工具说明](../tools/README.md) 完成构建，运行手动 GUI，熟悉目标输入、暂停、复位和状态读数。
2. 在 Arm 内实现规划与控制，通过手动调整目标观察机械臂响应，并在需要时开启 Trace。
3. 使用 benchmark 的程序参考重复运行，结合 CSV 中的目标、反馈、请求与实际力矩分析表现。
4. 根据记录解释算法的有效范围、问题和改进依据，保留能够对应代码与工况的结果。

`joint_sine` 是接入示例，不代表真实操作者，也不是已确定的教学验收集。

GUI 用于调试和定位运动阶段，正式评价使用 headless 与 Test 选项，命令见 [工具说明](../tools/README.md#benchmark)。运行状态和采样语义见 [Benchmark 与采集](benchmark.md)；CTest 检查框架契约，不替代教学任务验收。

## 教学工况

成员使用同一份实现依次解决姿态保持、单轴运动、连续跟随和多轴改目标。可按“先保持姿态，再分析单轴响应，最后处理连续与多轴运动”安排学习，不要求使用指定控制器或规划器。

| 工况 | 任务与关注点 |
| --- | --- |
| [posture_hold](../benchmark/cases/posture_hold/case.cpp) | 到达不同内部姿态并保持，观察重力负载下的误差与残余运动 |
| [joint_step](../benchmark/cases/joint_step/case.cpp) | 六轴分别进行正负、小幅及较大阶跃，比较主动轴响应与保持轴扰动 |
| [joint_tracking](../benchmark/cases/joint_tracking/case.cpp) | 六轴分别跟随慢、快两档正弦目标，观察输入变化速度对误差的影响 |
| [target_switch](../benchmark/cases/target_switch/case.cpp) | 多轴移动中撤回、反向，并组合 J4/J6 大幅运动，观察耦合与恢复过程 |

目标姿态、幅值、切换时间和阶段定义以工况代码为准，公共姿态见 [teaching.hpp](../benchmark/cases/teaching.hpp)。每项从模型零位重新开始，初始化记录保留，但不混入后续局部评价。`joint_sine` 保留为接入示例。

## 指标与解释

所有指标均按阶段、按关节计算。误差定义为原始目标减实际位置，包含内部规划与控制的整体效果。保持轴的最大目标偏差用于观察耦合，也包含该轴原有的保持误差。

| 场景 | 观察指标 |
| --- | --- |
| 姿态保持 | 位置误差均值、RMS、最大绝对值；速度 RMS 和峰值 |
| 恒定目标响应 | 主动轴到达时间、调节时间、方向性超调；保持轴最大偏差；完整阶段末 0.5 s 平均误差 |
| 连续跟随 | 主动轴位置误差 RMS、最大绝对值，以及保持轴最大偏差 |
| 各评价阶段 | 各轴峰值实际速度、峰值请求与实际力矩 |

到达统计使用位置误差不超过 1°、速度绝对值不超过 5°/s、连续保持至少 0.2 s 的口径。到达时间取首次满足该条件的区间起点；调节时间要求此后一直满足至阶段结束，且末段至少持续 0.2 s。时间均相对阶段开始，未满足时为 null 并给出原因。这是描述响应的统计口径，不是教学及格线。

超调按目标变化方向计算角度值；首个响应用初始反馈位置确定运动方向，后续响应用上一周期目标。连续跟随不计算阶跃超调。短于 0.5 s 的阶段不报告末段平均误差为稳态结果。

取消或失败后的完整阶段仍可评价；部分阶段只报告已观察到的误差、速度、力矩与超调，不给出完整响应的到达、调节或稳态结论。无样本不等于零误差。

本轮只提供实测指标，没有综合分数或性能通过结论。参考实现实测后再确定教学阈值；执行 completed 不表示跟随达标。峰值力矩也不能单独证明是否发生业务限幅。

## 成果记录建议

正式提交格式确定前，开发过程可保留以下内容，便于复核和后续讨论：

| 内容 | 用途 |
| --- | --- |
| 实现源码及对应版本或修改代码 | 确认记录来自哪份实现 |
| 算法与参数说明 | 解释内部规划、控制过程及参数选择依据 |
| 运行条件 | 记录模型、case ID、实际参数和相关模型修改 |
| [运行产物](benchmark.md#录制产物与结果) | 核对输入、反馈、输出和执行情况 |
| 结果解释 | 说明观察到的效果、失败情况与已知限制 |

这些是当前的记录建议，统一提交目录、命名和最终交付要求尚未确定。
