# 教学任务说明

本页说明教学目标、成员职责、工况及版本 1 的教学通过线。

## 教学目标

围绕同构控制器提供的六轴目标位置，让成员学习机械臂规划与控制，使机械臂能够快速、稳定地跟随目标，并能解释自己的算法选择与实际表现。训练在仿真中完成，获得的经验用于后续实物机械臂开发。

当前通过 GUI 手动输入和程序工况构造目标序列，成员不需要实际操作者输入即可开始调试。

学习内容包括理解关节目标和反馈、设计内部规划与控制过程、通过数据观察误差与振荡，以及分析模型约束和力矩限制对表现的影响。具体算法路线由成员设计，框架不预设 Arm 内部管线。

## 框架与成员职责

| 部分 | 当前职责 |
| --- | --- |
| 框架 | 模型与 MuJoCo 接入、目标输入、物理周期调度、关节反馈和力矩映射、GUI、benchmark 执行及统一 trace |
| 成员实现 | 在 `simulation/arm/` 内实现 Arm 的规划和控制逻辑，管理内部状态，在 update 中返回请求力矩，在 reset 中恢复内部状态 |
| 教学任务 | 给定参考工况、评价口径和通过线 |

实现从 [Arm](../simulation/arm/arm.hpp) 接入。成员可以自行组织 `simulation/arm/` 内部代码；共用输入输出接口、模型和记录格式是不同实现进行对比的基础。

### 实现边界

外部只提供目标位置，内部所需的参考加工、规划与控制由成员设计。接口字段、单位、周期时序和复位契约见 [架构说明](architecture.md#控制周期与接口)，坐标、零位和模型约束见 [资产说明](../assets/README.md)。

## 开发与观察

1. 按 [工具说明](../tools/README.md) 完成构建，运行手动 GUI，熟悉目标输入、暂停、复位和状态读数。
2. 在 Arm 内实现规划与控制，通过手动调整目标观察机械臂响应，并在需要时开启 Trace。
3. 使用 benchmark 的程序参考重复运行，结合 CSV 中的目标、反馈、请求与实际力矩分析表现。
4. 根据记录解释算法的有效范围、问题和改进依据，保留能够对应代码与工况的结果。

GUI 用于调试和定位运动阶段，正式评价使用 headless 与 Test 选项，命令见 [工具说明](../tools/README.md#benchmark)。运行状态和采样语义见 [Benchmark 与采集](benchmark.md)。

## 教学工况

成员使用同一份实现依次解决姿态保持、单轴运动、连续跟随和多轴改目标。首先关注到位后的稳定、超调、保持轴偏移及改目标后的恢复，再在这些条件下比较响应速度。可按“先保持姿态，再分析单轴响应，最后处理连续与多轴运动”安排学习，不要求使用指定控制器或规划器。

| 工况 | 任务与关注点 |
| --- | --- |
| [posture_hold](../benchmark/cases/posture_hold/case.cpp) | 到达不同内部姿态并保持，观察重力负载下的误差与残余运动 |
| [joint_step](../benchmark/cases/joint_step/case.cpp) | 六轴分别进行正负、小幅及较大阶跃，比较主动轴响应与保持轴扰动 |
| [joint_tracking](../benchmark/cases/joint_tracking/case.cpp) | 六轴依次跟随常规正弦目标，每轴之后恢复到固定姿态，再开始下一轴 |
| [target_switch](../benchmark/cases/target_switch/case.cpp) | 先完成多轴移动并返回基准姿态，再做腕部目标撤回、反向及 J4/J6 组合运动 |

目标姿态、幅值、切换时间和阶段定义以工况代码为准，公共姿态见 [teaching.hpp](../benchmark/cases/teaching.hpp)。每项从模型零位重新开始，初始化记录保留，但不混入后续局部评价。`joint_sine` 保留为接入示例。

[joint_tracking_stress](../benchmark/cases/joint_tracking_stress/case.cpp) 是单独选择的快速往返压力测试，用于观察输入变快时的误差及结束后的恢复。它与常规跟随使用相同的逐轴和恢复安排，参考周期更短，判定为 OBSERVE；all 执行常规工况。

## 指标与解释

所有指标均按阶段、按关节计算。误差定义为原始目标减实际位置，包含内部规划与控制的整体效果。保持轴的最大目标偏差包含原有保持误差与本阶段扰动；结合阶段开始时的误差、速度及是否进入统计误差带分析耦合。

| 场景 | 观察指标 |
| --- | --- |
| 姿态保持 | 位置误差均值、RMS、最大绝对值；速度 RMS 和峰值 |
| 恒定目标响应 | 主动轴到达时间、调节时间、方向性超调；保持轴最大偏差；完整阶段末 0.5 s 误差均值及 RMS |
| 连续跟随 | 主动轴位置误差 RMS、最大绝对值，以及保持轴最大偏差 |
| 跟随后恢复 | 单独记录误差、到达与调节时间、末段误差均值及 RMS，不与下一轴跟随合并 |
| 各评价阶段 | 各轴峰值实际速度、峰值请求与实际力矩 |

到达统计使用位置误差不超过 1°、速度绝对值不超过 5°/s、连续保持至少 0.2 s 的口径。到达时间取首次满足该条件的区间起点；调节时间要求此后一直满足至阶段结束，且末段至少持续 0.2 s。时间均相对阶段开始，未满足时为 null 并给出原因。这些误差带用于计算时间，具体通过条件见下节。

超调按目标变化方向计算角度值；首个响应用初始反馈位置确定运动方向，后续响应用上一周期目标。阶跃超调用于恒定目标响应阶段。末段误差均值及 RMS 要求阶段时长至少为 0.5 s。

取消或失败后，完整阶段照常评价；部分阶段报告已观察到的误差、速度、力矩与超调，到达、调节及稳态指标留空。无样本阶段标记为未记录。

## 教学通过线

通过规则版本为 1，首先要求稳定，再比较响应速度。所有适用关节、阶段和指标均须满足，不使用加权总分；比较使用未舍入数值，等于上限时满足要求。可执行规则集中在 [判定模块](../tools/python/benchmark/assessment.py)。

| 场景 | 通过条件 |
| --- | --- |
| posture_hold 保持段 | 六轴最大位置误差 ≤0.5°，速度 RMS ≤1°/s |
| joint_step 响应段 | 主动轴超调 ≤2°，调节时间 ≤1.5 s；保持轴最大偏差 ≤1° |
| joint_tracking 跟随段 | 主动轴误差 RMS ≤1°、最大误差 ≤2°；保持轴最大偏差 ≤1° |
| joint_tracking 恢复段 | 主动轴调节时间 ≤0.5 s；保持轴最大偏差 ≤1° |
| target_switch 完整响应段 | 主动轴超调 ≤2°，调节时间 ≤2 s；保持轴最大偏差 ≤1° |
| 上述完整响应段与恢复段的末 0.5 s | 六轴位置误差 RMS ≤0.5° |

末段 RMS 用于检查稳定性，有符号均值用于观察偏差方向。

target_switch 的 brief_target 和 resume_motion 是提前改目标的短段，检查主动轴超调和保持轴偏差。保持轴偏差按完整阶段数据检查，起始未进入统计带时另作提示。

初始化、姿态进入段、joint_sine 和 joint_tracking_stress 为 OBSERVE，用于观察和诊断。未知的旧教学阶段或缺失阶段为 INCOMPLETE。

判定针对本次选择的工况：全部必需检查完整且满足时为 PASS；完整数据存在超限或未能调节到位时为 FAIL；取消、部分记录或缺少适用数据时为 INCOMPLETE，并保留已发现的失败项。

结果提供逐项检查和离线报告，使用方式见 [工具说明](../tools/README.md#benchmark)，字段和图表说明见 [Benchmark 与采集](benchmark.md)。
